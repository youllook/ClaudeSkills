# ClaudeSkills

Claude Code skills 合集，依用途分類。A categorized collection of Claude Code skills.

## 安裝

把想用的 skill 資料夾複製到 `~/.claude/skills/`（Windows：`C:\Users\<你>\.claude\skills\`），重開 session 即可。
